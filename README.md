# О проекте


**Film library** - сервис поиска и управления коллекцией фильмов. 
Позволяет пользователям:
- искать фильмы;
- добавлять их в избранное;
- добавлять в просмотренное;
- просматривать свою коллекцию;
- выгружать свою библиотеку в CSV-файл.

*Для получения ключа OMDb API обратитесь к администратору проекта*
