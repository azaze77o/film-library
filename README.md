# О проеке


**Film library** - сервис по ведению видеотеки. 
Позволяет пользователям искать фильмы, добавлять их в избранное, добавлять в просмотренное, формировать отчетность.

# Use Case

1. Поиск фильмов по названию (превью) - реализовано;
2. Поиск фильма (карточка фильма) - не реализовано;
    - По названию;
    - По ID.
3. Добавление фильма
    - в ибранное - не реализовано;
    - в просмотренное - не реализовано;
    - В список рекомендаций - не реалзоивано.
4. Отчность:
    - Экспорт результатов поиска - реализовано.
